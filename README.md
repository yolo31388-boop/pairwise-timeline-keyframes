# pairwise-timeline-keyframes

拖时间线到两个关键帧中间，画面突然跳一下，插值模式写的是贝塞尔但控制柄按线性算；时间重映射后关键帧时间没跟着缩放，慢动作段的关键帧挤在一起；嵌套序列的局部时间与父级时间相加，子序列被播放两次；变速关键帧只改了播放速度没改音频采样位置，口型对不上；工程帧率从 25 改成 30，已有 keyframe 按帧号存储导致整体偏移；裁剪片段后关键帧还留在原绝对时间，重新拖入时位置错乱；撤销只回滚了关键帧值没回滚控制柄，曲线变形；缓存按片段 id 索引，改一个关键帧后整段仍显示旧帧；多层轨道的关键帧吸附按像素而非时间，缩放时间线后对齐全乱；导出时只采样整数帧，两个 keyframe 之间的极值被漏掉。media/timeline_keyframes.py 是核心，tests/test_timeline_keyframes.py 15个红。要修的是：贝塞尔控制柄参与求值；重映射同步关键帧；嵌套时间只加一次；变速同步音频；关键帧按时间存储；裁剪偏移关键帧；撤销含控制柄；缓存按内容哈希失效；吸附按时间量化；导出按子帧采样。

## 运行

```bash
python -m pytest tests -q
```
